# Deanonymization of Tor Network using Traffic Analysis

## Overview
This project focuses on analyzing network traffic patterns in the Tor Network to study possible deanonymization techniques using traffic correlation and machine learning-based analysis. The system aims to understand how traffic behavior can be used to identify communication patterns while maintaining an ethical and research-oriented approach.

The project is developed for academic and cybersecurity research purposes only.

---

## Features

- Tor traffic data collection and preprocessing
- Traffic flow and packet analysis
- Visualization of network activity
- Correlation-based traffic analysis
- Machine Learning based prediction models
- Interactive dashboard for monitoring results
- Data logging and report generation
